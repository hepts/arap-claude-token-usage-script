# token-usage.sh

Claude Code の JSONL セッションログから、**セッション毎のトークン消費量と概算コスト**をサッと集計するシェルスクリプトです。

Claude Code は各セッションのやり取りを `~/.claude/projects/<プロジェクト>/<セッションID>.jsonl` に保存しており、各アシスタントメッセージに `usage`（入力・出力・キャッシュ作成・キャッシュ読み取りのトークン数）が記録されています。本スクリプトはこれを読み取り、モデル別料金でコストを計算して一覧・詳細表示します。

## 特徴

- **4種のトークンをすべて集計** — input / output / cache作成 / cache読み取り
- **cache作成を 5分 (`ephemeral_5m`) と 1時間 (`ephemeral_1h`) で別単価計算** — 料金が異なるため正確に按分
- **メッセージ単位でモデルを判定** — サブエージェント（sidechain）が別モデルでも正しく計算し、`*` 印で区別
- **ストリーミング分割の重複を排除** — `message.id` で二重計上を防止。分割された行のうち最後の行（確定した `output_tokens`）を採用
- **リクエスト単位の料金補正に対応** — Haiku 5.5 の長文プロンプト料金（10万トークン超）、Fast mode（`usage.speed == "fast"`）、`inference_geo: "us"` の 1.1 倍
- 料金表に無いモデルは黙って $0 にせず `⚠料金不明` を表示
- 追加の依存なし（macOS / Linux 標準の `bash` + `python3` のみ）

## 必要環境

- `bash`（macOS の `/bin/sh` = bash 3.2 POSIX モードで起動された場合も自動で通常 bash に再実行します）
- `python3`
- Claude Code のログ（`~/.claude/projects/` 配下）

## インストール

```bash
git clone <this-repo>
cd <this-repo>
chmod +x token-usage.sh
```

## 使い方

```bash
./token-usage.sh                    # カレントディレクトリのプロジェクトの全セッション
./token-usage.sh -a                 # 全プロジェクトの全セッション
./token-usage.sh -n 5               # 直近5セッションだけ
./token-usage.sh -p <project-dir>   # ~/.claude/projects/ 配下のプロジェクト名を指定
./token-usage.sh -d <session-id>    # 指定セッションをメッセージ単位で詳細表示
./token-usage.sh <session-id|path>  # 指定セッションのみ集計
./token-usage.sh --json             # 集計結果を JSON で出力
./token-usage.sh -h                 # ヘルプ
```

`<session-id>` は先頭数文字だけでも前方一致で探します（例: `a1b2c3d4`）。

### 列の意味

| 列 | 内容 |
|----|------|
| `in`      | 入力トークン（`input_tokens`） |
| `out`     | 出力トークン（`output_tokens`） |
| `cache_w` / `w5m` `w1h` | キャッシュ作成トークン。`w5m`=5分キャッシュ、`w1h`=1時間キャッシュ |
| `cache_r` / `read` | キャッシュ読み取りトークン（`cache_read_input_tokens`） |
| `msg`     | 集計対象のアシスタントメッセージ数 |
| `cost$`   | 概算コスト（USD） |
| `*`（詳細表示） | サブエージェント（sidechain）のメッセージ |

## 料金表

料金はスクリプト内の Python 部 `PRICING` にハードコードしています（USD / MTok、**2026-11-26 時点**の公式料金表）。改定時やモデル追加時はここを編集してください。

| モデル | in | out | w5 | w1 | read |
|---|---:|---:|---:|---:|---:|
| `claude-fable-5-2` / `claude-mythos-5-2` | 8 | 40 | 10 | 16 | 0.20 |
| `claude-fable-5-1` / `claude-mythos-5-1` | 10 | 50 | 12.50 | 20 | 0.25 |
| `claude-fable-5` / `claude-mythos-5` | 10 | 50 | 12.50 | 20 | 1.00 |
| `claude-opus-5-5` | 4 | 20 | 5 | 8 | 0.20 |
| `claude-opus-5` / `4-8` / `4-7` / `4-6` / `4-5` | 5 | 25 | 6.25 | 10 | 0.50 |
| `claude-opus-4-1` / `claude-opus-4` | 15 | 75 | 18.75 | 30 | 1.50 |
| `claude-sonnet-5-5` | 2 | 10 | 2.50 | 4 | 0.10 |
| `claude-sonnet-5` | 2 | 10 | 2.50 | 4 | 0.20 |
| `claude-sonnet-4-6` / `4-5` / `claude-sonnet-4` | 3 | 15 | 3.75 | 6 | 0.30 |
| `claude-haiku-5-5`（プロンプト10万トークン以下） | 0.10 | 0.50 | 0.125 | 0.20 | 0.01 |
| `claude-haiku-5-5`（プロンプト10万トークン超） | 0.50 | 2.50 | 0.625 | 1 | 0.05 |
| `claude-haiku-4-5` | 1 | 5 | 1.25 | 2 | 0.10 |

- `w5` = 5分キャッシュ作成、`w1` = 1時間キャッシュ作成、`read` = キャッシュ読み取り。
- Haiku 5.5 は、1リクエストのプロンプト長（input + cache作成 + cache読み取り）が 100,000 トークンを超えると、そのリクエストの全トークンが上段ではなく下段の料金になります。
- Fast mode（`FAST_PRICING`）は Fable 5.2 / Mythos 5.2 が $16 / $80、Opus 5.5 が $8 / $40、Opus 5 / Opus 4.8 が $10 / $50 です。キャッシュ料金は Fast mode の input 単価に通常のキャッシュ倍率を掛けて算出します。料金表に Fast mode 単価が無いモデルで `speed: "fast"` が記録されていた場合は `⚠fast料金不明` を表示します。
- `inference_geo: "us"` のリクエストは全単価を 1.1 倍します。
- モデルID は日付サフィックス（例 `claude-haiku-4-5-20251001`）、`[1m]` サフィックス、`global.anthropic.` のような Bedrock 形式の接頭辞を取り除いてから完全一致で引きます。前方一致にすると `claude-sonnet-5-5` が `claude-sonnet-5` の料金で計算されてしまうためです。
- 最新の公式料金はこちら → https://platform.claude.com/docs/en/about-claude/pricing

## 注意事項

- **表示日時は UTC** です（ログの `timestamp` をそのまま表示）。JST で見たい場合はスクリプトを調整してください。
- **料金は概算**です。料金表に無いモデルは `⚠料金不明` となり、トークン数は正確ですがコストは 0 として集計されます。正確なコストが必要な場合は `PRICING` に該当モデルを追加してください。
- Amazon Bedrock や Google Cloud 経由のログも、Claude API（ファーストパーティ）の料金で計算します。各クラウドの料金とは一致しない場合があります。
- Batch API の割引や、組織ごとの割引は反映していません。
- `<synthetic>`（Claude Code が内部生成する擬似メッセージ）はコスト 0・警告なしで扱います。
- 集計はローカルのログを読むだけで、外部への通信は一切行いません。
