# token-usage.sh

Claude Code の JSONL セッションログから、**セッション毎のトークン消費量と概算コスト**をサッと集計するシェルスクリプトです。

Claude Code は各セッションのやり取りを `~/.claude/projects/<プロジェクト>/<セッションID>.jsonl` に保存しており、各アシスタントメッセージに `usage`（入力・出力・キャッシュ作成・キャッシュ読み取りのトークン数）が記録されています。本スクリプトはこれを読み取り、モデル別料金でコストを計算して一覧・詳細表示します。

## 特徴

- **4種のトークンをすべて集計** — input / output / cache作成 / cache読み取り
- **cache作成を 5分 (`ephemeral_5m`) と 1時間 (`ephemeral_1h`) で別単価計算** — 料金が異なるため正確に按分
- **メッセージ単位でモデルを判定** — サブエージェント（sidechain）が別モデルでも正しく計算し、`*` 印で区別
- **ストリーミング分割の重複を排除** — `message.id` で二重計上を防止
- 料金表に無いモデルは黙って $0 にせず `⚠料金不明` を表示
- 追加の依存なし（macOS / Linux 標準の `bash` + `python3` のみ）

## 必要環境

- `bash`（macOS の `/bin/sh` = bash 3.2 POSIX モードで起動された場合も自動で通常 bash に再実行します）
- `python3`
- Claude Code のログ（`~/.claude/projects/` 配下）

## インストール

```bash
git clone <this-repo>
cd <this-repo>
chmod +x token-usage.sh
```

## 使い方

```bash
./token-usage.sh                    # カレントディレクトリのプロジェクトの全セッション
./token-usage.sh -a                 # 全プロジェクトの全セッション
./token-usage.sh -n 5               # 直近5セッションだけ
./token-usage.sh -p <project-dir>   # ~/.claude/projects/ 配下のプロジェクト名を指定
./token-usage.sh -d <session-id>    # 指定セッションをメッセージ単位で詳細表示
./token-usage.sh <session-id|path>  # 指定セッションのみ集計
./token-usage.sh --json             # 集計結果を JSON で出力
./token-usage.sh -h                 # ヘルプ
```

`<session-id>` は先頭数文字だけでも前方一致で探します（例: `a1b2c3d4`）。

### 列の意味

| 列 | 内容 |
|----|------|
| `in`      | 入力トークン（`input_tokens`） |
| `out`     | 出力トークン（`output_tokens`） |
| `cache_w` / `w5m` `w1h` | キャッシュ作成トークン。`w5m`=5分キャッシュ、`w1h`=1時間キャッシュ |
| `cache_r` / `read` | キャッシュ読み取りトークン（`cache_read_input_tokens`） |
| `msg`     | 集計対象のアシスタントメッセージ数 |
| `cost$`   | 概算コスト（USD） |
| `*`（詳細表示） | サブエージェント（sidechain）のメッセージ |

## 料金表

料金はスクリプト冒頭の Python 部 `PRICING` にハードコードしています（USD / MTok、**2026-07-20 時点**）。改定時やモデル追加時はここを編集してください。

```python
PRICING = {
    "claude-opus-4-8":  {"in": 5.0,  "out": 25.0, "w5": 6.25,  "w1": 10.0, "read": 0.5},
    "claude-sonnet-5":  {"in": 2.0,  "out": 10.0, "w5": 2.50,  "w1": 4.0,  "read": 0.2},
    "claude-fable-5":   {"in": 10.0, "out": 50.0, "w5": 12.50, "w1": 20.0, "read": 1.0},
    "claude-haiku-4-5": {"in": 1.0,  "out": 5.0,  "w5": 1.25,  "w1": 2.0,  "read": 0.1},
    # ...
}
```

- `w5` = 5分キャッシュ作成、`w1` = 1時間キャッシュ作成、`read` = キャッシュ読み取り。
- モデルID はバージョンサフィックス（例 `claude-haiku-4-5-20251001`）を前方一致で吸収します。
- 最新の公式料金はこちら → https://platform.claude.com/docs/en/pricing

## 注意事項

- **表示日時は UTC** です（ログの `timestamp` をそのまま表示）。JST で見たい場合はスクリプトを調整してください。
- **料金は概算**です。料金表に無いモデル（旧世代の一部など）は `⚠料金不明` となり、トークン数は正確ですがコストは 0 として集計されます。正確なコストが必要な場合は `PRICING` に該当モデルを追加してください。
- `<synthetic>`（Claude Code が内部生成する擬似メッセージ）はコスト 0・警告なしで扱います。
- 集計はローカルのログを読むだけで、外部への通信は一切行いません。
